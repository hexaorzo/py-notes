01 What is a String?
Concept
  • A sequence of characters — letters, digits, spaces, symbols.
  • Written inside "..." or '...' (be consistent).
  • Supports concatenation (+) and repetition (*).
✗ Mistake: "age=" + 20 → TypeError
✓ Fix: "age=" + str(20) or use an f-string
Examples
a = "me"
b = "myself"
print(a + b)       # "memyself"
print(a + " " + b) # "me myself"
print(a * 3)       # "mememe"
02 len() and Indexing
Concept
  • len(s) — returns the length of the string.
  • Indexing uses [], starts from 0.
  • Negative index: -1 is the last character.
✗ Mistake: s[3] for "abc" → IndexError
✓ Fix: last valid index is len(s) - 1
Demo
s = "abc"
print(len(s))          # 3
print(s[0], s[1], s[2]) # a b c
print(s[-1], s[-2])    # c b
03 Slicing — s[start:stop:step]
Concept
  • Extracts a substring without modifying the original.
  • Includes start, excludes stop.
  • Defaults: start=0, stop=end, step=1.
  • Negative step reverses direction. s[::-1] = reversed string.
✗ Mistake: thinking s[1:4] includes index 4
✓ Fix: stop is always excluded
✗ Mistake: s[5:2] for forward slice
✓ Fix: use s[5:2:-1] with negative step
Demo
s = "abcdef"
s[1:4]   # "bcd"
s[:3]    # "abc"
s[3:]    # "def"
s[::2]   # "ace"
s[::-1]  # "fedcba"
04 Membership: in and not in
Concept
  • Checks if a character or substring exists in the string.
  • Returns True or False. Case-sensitive.
  • Works for both single chars and substrings.
✗ Mistake: if "Py" == s to check containment
✓ Fix: use if "Py" in s
Demo
s = "Programming in Python"
print("Python" in s)  # True
print("python" in s)  # False
print("Java" not in s) # True
05 Strings are Immutable
Concept
  • Characters cannot be changed by index after creation.
  • Any "modification" creates a new string.
✗ Mistake: s[0] = "H" → TypeError
✓ Fix: s2 = "H" + s[1:] or use .replace()
Demo
s = "hello"
# s[0] = "H"  → ERROR
s2 = "H" + s[1:]
print(s)   # "hello" unchanged
print(s2)  # "Hello"
06 Concatenation, Repetition & Comparison
Concept
  • + concatenates, * repeats.
  • Comparisons use lexicographic order (ASCII/Unicode codes).
  • Uppercase letters come before lowercase in ASCII → "Z" < "a" is True.
✗ Mistake: "20" > "3" → False (string comparison!)
✓ Fix: convert first: int("20") > int("3")
Demo
a = "abc"; b = "abd"
print(a + "XYZ")  # "abcXYZ"
print("ha" * 4)    # "hahahaha"
print(a == b)     # False
print(a < b)      # True (c < d)
print("Z" < "a")  # True (ASCII)
07 Built-ins: len, min, max, sorted
Concept
  • len(s) — length
  • min(s), max(s) — smallest/largest character (lexicographic)
  • sorted(s) — returns a list of sorted characters
✗ Mistake: expecting sorted(s) to return a string
✓ Fix: "".join(sorted(s))
Demo
s = "dbca"
print(len(s))            # 4
print(min(s), max(s))    # a d
print(sorted(s))         # ['a','b','c','d']
print("".join(sorted(s))) # "abcd"
08 Case Methods: lower, upper, title, capitalize
Concept
  • .lower() — all lowercase
  • .upper() — all uppercase
  • .title() — capitalizes each word's first letter
  • .capitalize() — capitalizes only the first character
✗ Mistake: s.lower (missing parentheses)
✓ Fix: always call: s.lower()
Demo
s = "pYtHon proGramming"
print(s.lower())      # "python programming"
print(s.upper())      # "PYTHON PROGRAMMING"
print(s.title())      # "Python Programming"
print(s.capitalize()) # "Python programming"
09 Whitespace: strip, lstrip, rstrip
Concept
  • Removes leading/trailing whitespace (spaces, tabs, newlines).
  • .strip() — both sides
  • .lstrip() — left only  |  .rstrip() — right only
✗ Mistake: thinking strip() removes spaces in the middle
✓ Fix: it only affects the ends
Demo
s = " hello world \n"
print("[" + s.strip()  + "]") 
# [hello world]
print("[" + s.lstrip() + "]") 
# [hello world \n]
print("[" + s.rstrip() + "]") 
# [ hello world]
10 Searching: find, rfind, index, count
Concept
  • .find(sub) — first index, or -1 if not found (safe)
  • .rfind(sub) — last occurrence
  • .index(sub) — like find, but raises error if not found
  • .count(sub) — counts all occurrences
✗ Mistake: if s.find("x"): — 0 is falsy!
✓ Fix: if s.find("x") != -1: or "x" in s
Demo
s = "banana"
print(s.find("na"))   # 2
print(s.rfind("na"))  # 4
print(s.count("na"))  # 2
print(s.find("x"))   # -1
11 replace(old, new, count)
Concept
  • Replaces occurrences of old with new.
  • Optional count limits how many replacements are made.
  • Returns a new string (immutability).
✗ Mistake: expecting replace() to modify original
✓ Fix: s = s.replace(...)
Demo
s = "one one one"
print(s.replace("one", "1"))    
# "1 1 1"
print(s.replace("one", "1", 2)) 
# "1 1 one"
12 split() and join()
Concept
  • .split(sep) — string → list of pieces
  • split() with no arg splits on any whitespace (handles multiple spaces)
  • "sep".join(list) — list → string
  • Use .strip() after splitting to clean tokens.
✗ Mistake: parts.join(" | ")
✓ Fix: " | ".join(parts) — join is a string method
Demo
line = "CSE, SAARC, Delhi"
parts = line.split(",")
clean = [p.strip() for p in parts]
result = " | ".join(clean)
print(result) # "CSE | SAARC | Delhi"

# split() vs split(" ")
" IIT Delhi CSE ".split()
# ['IIT', 'Delhi', 'CSE']
13 startswith() and endswith()
Concept
  • Safer than slicing for prefix/suffix checks.
  • Can pass a tuple to check multiple options at once.
Demo
s = "report_final.pdf"
print(s.endswith(".pdf"))           # True
print(s.startswith("report"))        # True
print(s.endswith((".pdf", ".docx"))) # True
14 f-strings (Formatted String Literals)
Concept
  • Inserts values and expressions directly inside {}.
  • Eliminates type-conversion issues like str(n).
  • Any valid Python expression can go inside {}.
✗ Mistake: forgetting the f prefix
✓ Fix: f"..." is required
Demo
name = "Raj"
score = 92
print(f"{name} scored {score} marks")
# "Raj scored 92 marks"
print(f"square = {score * score}")
# "square = 8464"
15 Pattern Matching (No Imports Needed)
Concept
  • Beginner-level pattern matching with: in, find(), startswith(), endswith()
  • Split-based validation is cleaner than regex for beginners.
✗ Mistake: treating "@" in email as full validation
✓ Fix: also check one @, non-empty local part, and . in domain
Basic Email Validator
email = "abc@sau.ac.in"
if "@" in email:
    parts = email.split("@")
    if (len(parts) == 2 and
        parts[0] != "" and
        "." in parts[1]):
        print("Valid format")
    else:
        print("Invalid")
16 Escape Sequences & Raw Strings
Escape Sequences
  • \n — newline
  • \t — tab
  • \\ — literal backslash
  • \", \' — quotes inside strings
Raw Strings

Prefix with r"..." — backslashes are treated literally. Great for file paths.

✗ Mistake: "C:\new\test" → \n becomes newline!
✓ Fix: "C:\\new\\test" or r"C:\new\test"
Demo
s1 = "Line1\nLine2"   # two lines
s2 = "A\tB\tC"       # tab-separated
s3 = "He said: \"Hi\""

path1 = "C:\\new\\test"
path2 = r"C:\new\test"
# path1 == path2 → True
17 Character Category Methods
Methods (return True/False)
  • .isalpha() — only letters
  • .isdigit() — only digits
  • .isalnum() — letters or digits
  • .isspace() — spaces/tabs only
  • .islower() / .isupper()
✗ Mistake: "12.5".isdigit() → False (. is not a digit)
✓ Fix: for negative numbers, check s[0]=='-' and s[1:].isdigit()
Demo
"Raj".isalpha()   # True
"123".isdigit()   # True
"12.5".isdigit()  # False
"Raj123".isalnum()# True
"PYTHON".isupper() # True
"python".islower() # True
18 ord() and chr() — ASCII / Unicode
Concept
  • ord(ch) — character → integer code
  • chr(n) — integer code → character
  • Uppercase (A=65) and lowercase (a=97) have different codes.
  • Useful for ciphers, shifts, understanding comparisons.
Demo
print(ord('A'))  # 65
print(ord('a'))  # 97
print(chr(65))   # 'A'
print(chr(97))   # 'a'
print(ord('Z') < ord('a'))
# True (90 < 97)
19 Alignment, zfill & removeprefix/removesuffix
Alignment
s = "Python"
print("[" + s.center(12) + "]")
# [   Python   ]
print("[" + s.ljust(12)  + "]")
# [Python      ]
print("[" + s.rjust(12)  + "]")
# [      Python]
zfill & removeprefix / removesuffix
"7".zfill(3)       # "007"
"42".zfill(5)      # "00042"
"-9".zfill(4)      # "-009"

"unhappy".removeprefix("un")  
# "happy"
"report.pdf".removesuffix(".pdf")
# "report"
20 Logic Building — Manual Traversal
Palindrome
s = "Madam"
if s.lower() == s.lower()[::-1]:
    print("Palindrome")
Count Char Types
v = c = d = sp = 0
for ch in s:
  if ch.isalpha():
    if ch in "AEIOUaeiou":
      v += 1
    else: c += 1
  elif ch.isdigit(): d += 1
  elif ch == ' ': sp += 1
Word Count (No split)
wds = 0; in_wd = False
for ch in s:
  if ch != ' ' and not in_wd:
    wds += 1; in_wd = True
  elif ch == ' ':
    in_wd = False
print(wds)
