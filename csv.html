01 What is a CSV File?
Concept
  • CSV = Comma-Separated Values.
  • Stores tabular data (rows & columns) as plain text.
  • Each line = one record; values separated by commas.
  • First line is usually the header (column names).
  • Widely supported by Excel, databases, and APIs.
Key point: CSV is a plain text format, but it represents structured tabular data.
Example CSV
# students.csv
name,marks,grade
Aman,87,A
Ravi,76,B
Neha,91,A
Why CSV is popular
  • Simple and human-readable
  • Works with spreadsheet tools
  • Easy to share between programs
02 Why Use the csv Module?
Without csv module (manual)
with open("students.txt", "r") as f:
    for line in f:
        parts = line.strip().split(",")
        name  = parts[0]
        marks = int(parts[1])
        grade = parts[2]
✗ Breaks when: a value contains a comma (e.g. "Smith, Jr")
Why manual logic is fragile
  • Must manually strip newlines
  • Must split by comma yourself
  • Fails if a field contains a comma
  • Header handling is manual
  • No standard write format
Key point: The csv module handles quoting, escaping, and row structure automatically.

04 Importing the csv Module
Import
import csv
Key tools provided
  • csv.reader() — reads rows as lists
  • csv.writer() — writes list rows
  • csv.DictReader() — reads rows as dicts
  • csv.DictWriter() — writes dict rows
✗ Mistake: Using csv.reader() without importing → NameError
✓ Fix: Always write import csv at the top
Basic template
import csv

with open("students.csv", "r",
           encoding="utf-8") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
05 Reading CSV with csv.reader()
Concept
  • csv.reader(f) creates a reader object.
  • Each row is returned as a list of strings.
  • Header row is read like any other row.
  • Values are accessed by index: row[0], row[1]…
Key point: csv.reader() reads CSV row by row; each row is a list.
Code & Output
import csv
with open("students.csv", "r",
           encoding="utf-8") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)

# ['name', 'marks', 'grade']
# ['Aman', '87', 'A']
# ['Ravi', '76', 'B']
# ['Neha', '91', 'A']
06 CSV Values are Always Read as Strings
Concept
  • Every value from a CSV file is a string, even numbers.
  • "87" is NOT the integer 87.
  • For arithmetic, you must convert explicitly.
✗ Mistake: total += row[1] → adds strings, not numbers
✓ Fix: total += int(row[1])
Key point: Always convert numeric fields with int() or float() before computation.
Proof
for row in reader:
    print(row, type(row[1]))

# ['name', 'marks'] <class 'str'>
# ['Aman', '87']    <class 'str'>
# ['Ravi', '76']    <class 'str'>
Conversion
marks = int(row[1])     # integer
price = float(row[2])  # decimal
07 Skipping the Header Row
Concept
  • The first row is often column names, not data.
  • Use next(reader) to consume it before the loop.
  • Store it in a variable if the header is needed later.
✗ Mistake: Calling int(row[1]) on the header row → ValueError: invalid literal 'marks'
✓ Fix: Call next(reader) before the loop
Code
import csv
with open("students.csv", "r",
           encoding="utf-8") as f:
    reader = csv.reader(f)
    header = next(reader)   # skip header
    for row in reader:
        name  = row[0]
        marks = int(row[1])
        grade = row[2]
        print(name, marks, grade)

# Aman 87 A
# Ravi 76 B
# Neha 91 A
08 Calculating Total and Average
Steps involved
  • Skip header with next(reader)
  • Convert marks to int per row
  • Accumulate total and count
  • Divide after the loop for average
Key point: CSV reading + type conversion + accumulation is a very common pattern.
Code & Output
import csv
total = 0; count = 0
with open("students.csv", "r",
           encoding="utf-8") as f:
    reader = csv.reader(f)
    next(reader)
    for row in reader:
        marks  = int(row[1])
        total += marks
        count += 1

average = total / count
print("Total =",   total)    # 322
print("Average =", average)  # 80.5
09 Filtering Records
Concept
  • Add an if condition inside the row loop.
  • Convert the field to the right type before comparing.
  • Process or print only rows that match the condition.
Key point: CSV processing is commonly used for filtering, searching, summarising, and reporting.
Print students with marks ≥ 80
import csv
with open("students.csv", "r",
           encoding="utf-8") as f:
    reader = csv.reader(f)
    next(reader)
    for row in reader:
        name  = row[0]
        marks = int(row[1])
        grade = row[2]
        if marks >= 80:
            print(name, marks, grade)

# Aman 87 A
# Neha 91 A
10 Writing CSV with csv.writer()
Concept
  • Open file in write mode "w" with newline="".
  • csv.writer(f) creates a writer object.
  • writerow(list) writes one row as a list.
  • First call is usually the header row.
✗ Mistake: Opening without newline="" may add extra blank lines between rows on Windows
✓ Fix: Always use open(..., newline="") when writing CSV
Code
import csv
with open("students.csv", "w",
           newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "marks", "grade"])
    writer.writerow(["Aman", 87, "A"])
    writer.writerow(["Ravi", 76, "B"])
    writer.writerow(["Neha", 91, "A"])

# File: name,marks,grade
#       Aman,87,A  ...
11 Writing Multiple Rows with writerows()
Concept
  • writerow() → writes one row (one list).
  • writerows() → writes many rows (list of lists).
  • Useful when data is already collected in a nested list.
Key point: writerows() saves you from calling writerow() in a loop.
Code
import csv
records = [
    ["name", "marks", "grade"],
    ["Aman", 87, "A"],
    ["Ravi", 76, "B"],
    ["Neha", 91, "A"]
]
with open("students.csv", "w",
           newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerows(records)
12 Reading as Dictionary — csv.DictReader()
Concept
  • Each row is returned as a dictionary.
  • Column names become dictionary keys automatically.
  • No need to call next() — header is consumed automatically.
  • Access values by name: row["marks"] instead of row[1].
Key point: DictReader improves readability because fields are accessed by meaningful column names.
Code & Output
import csv
with open("students.csv", "r",
           encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row)

# {'name':'Aman','marks':'87','grade':'A'}
# {'name':'Ravi','marks':'76','grade':'B'}
# {'name':'Neha','marks':'91','grade':'A'}
name  = row["name"]
marks = int(row["marks"])
grade = row["grade"]
13 Filtering Records with DictReader
Why DictReader is better for filtering
  • row["name"] is clearer than row[0].
  • Code remains readable even with many columns.
  • Adding/removing columns in CSV doesn't break index-based access.
Key point: Prefer DictReader when the CSV has meaningful column headers.
Code — marks ≥ 80
import csv
with open("students.csv", "r",
           encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        name  = row["name"]
        marks = int(row["marks"])
        grade = row["grade"]
        if marks >= 80:
            print(name, marks, grade)

# Aman 87 A
# Neha 91 A
14 Writing Dictionaries — csv.DictWriter()
Concept
  • fieldnames defines the column order.
  • writeheader() writes the header row first.
  • writerows(records) writes a list of dicts.
  • Each dict key must match a field name.
Key point: DictWriter is ideal when records are naturally stored as dictionaries.
Code
import csv
records = [
    {"name":"Aman", "marks":87, "grade":"A"},
    {"name":"Ravi", "marks":76, "grade":"B"},
]
with open("students.csv", "w",
           newline="", encoding="utf-8") as f:
    fields = ["name", "marks", "grade"]
    writer = csv.DictWriter(f, fieldnames=fields)
    writer.writeheader()
    writer.writerows(records)
15 Why newline="" is Used When Writing
Explanation
  • Python's default file mode translates \n on Windows, adding extra blank lines to CSV output.
  • newline="" disables that translation and lets the csv module handle line endings.
  • It does not mean rows won't advance to the next line.
  • Only needed when writing, not reading.
✗ Without newline="": blank lines appear between every row on Windows
✓ With newline="": clean output, one row per line
Correct pattern
# Always write CSV like this:
with open("out.csv", "w",
           newline="",        # ← key
           encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "marks"])
    writer.writerow(["Aman", 87])
Rule: newline="" is recommended whenever you open a file for CSV writing.

17 Common CSV Mistakes
✗ Forgetting import csv
→ NameError: name 'csv' is not defined
✓ Always add import csv at the top
✗ Not skipping header before int(row[1])
→ ValueError: invalid literal for int() with base 10: 'marks'
✓ Call next(reader) before the loop
✗ total += row[1] instead of int(row[1])
→ Concatenates strings instead of adding numbers
✓ Convert: total += int(row[1])
✗ Missing newline="" while writing
→ Extra blank lines in file on Windows
✓ open("f.csv", "w", newline="")
✗ Wrong field name in DictReader: row["mark"]
→ KeyError: 'mark'
✓ Check the exact column name in the file: row["marks"]
✗ Opening for write without specifying mode
→ Default "r" mode → can't write
✓ Use open("f.csv", "w", newline="")
