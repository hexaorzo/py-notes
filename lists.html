Lists in Python

Topics: Collections · Creation · Indexing · Slicing · Mutation · Methods · Aliasing · Comprehension

Why Collections?

  • One variable stores only one value
  • Related values need grouping (marks, cities, prices)
  • Separate variables → repetitive, unscalable code
  • Grouped structures support loops and processing

List at a Glance

  • Ordered — preserves insertion sequence
  • Mutable — elements can be changed
  • Allows duplicates
  • Supports indexing, slicing, loops
  • Can store mixed data types

Syntax Distinctions

  • [] → list
  • () → tuple
  • {val, ...} → set
  • {k: v} → dictionary
  • {} alone → dict, not set!

Sequence Types

  • String, List, Tuple are sequence types
  • All support indexing and slicing
  • Set and Dict are not positional
  • List follows naturally after String study

Four Built-in Collection Types

Type Ordered Mutable Duplicates Access Syntax
List Yes Yes Yes by index [1, 2, 3]
Tuple Yes No Yes by index (1, 2, 3)
Set No Yes No membership {1, 2, 3}
Dictionary key-based Yes keys unique by key {"k": v}

01 Creating Lists — Four Ways
Methods
  • Literal — most common, direct values in []
  • Empty — [] or list()
  • list() constructor — converts any iterable
  • From range() — list(range(n))
⚑ Note: list("python") splits into individual characters, not words
Demo
L1 = [1, 2, 3, 4]
L2 = []
L3 = list("python")
L4 = list(range(5))
print(L1)  # [1, 2, 3, 4]
print(L2)  # []
print(L3)  # ['p','y','t','h','o','n']
print(L4)  # [0, 1, 2, 3, 4]
02 Indexing — Accessing by Position
Concept
  • Every element has a position called an index.
  • Indexing starts from 0, not 1.
  • First element → index 0; Last → index n-1
✗ Mistake: thinking index starts from 1
✓ Fix: first element is always L[0]
Demo
colors = ["red", "green", "blue", "yellow"]
print(colors[0])  # red
print(colors[1])  # green
print(colors[3])  # yellow (4th element)
03 Negative Indexing — Access from the End
Concept
  • -1 → last element
  • -2 → second last, and so on
  • Avoids writing L[len(L) - 1]
Demo
colors = ["red", "green", "blue", "yellow"]
print(colors[-1])  # yellow
print(colors[-2])  # blue
print(colors[-4])  # red
04 len() and IndexError
Concept
  • len(L) → total count of elements
  • Length ≠ last index. If len=5, last valid index is 4.
  • Accessing out-of-range index → IndexError
✗ Mistake: L[len(L)] → IndexError
✓ Fix: use L[len(L) - 1] or L[-1]
Demo
nums = [10, 20, 30, 40, 50]
print(len(nums))  # 5
# valid indices: 0,1,2,3,4
# nums[5] → IndexError !

empty = []
print(len(empty))  # 0
05 Slicing — L[start:stop]
Concept
  • Extracts a new sublist; original is unchanged.
  • start is included, stop is excluded.
  • Omitting start → from beginning; omitting stop → till end.
✗ Mistake: thinking L[1:4] includes index 4
✓ Fix: stop is always excluded → gives indices 1, 2, 3
Demo
nums = [10, 20, 30, 40, 50, 60]
nums[1:4]  # [20, 30, 40]
nums[:3]   # [10, 20, 30]
nums[3:]   # [40, 50, 60]
nums[:]    # [10, 20, 30, 40, 50, 60]
06 Slicing with Step — L[start:stop:step]
Concept
  • Step controls how many positions to skip.
  • ::2 → alternate elements
  • ::-1 → full reverse copy (common pattern)
Demo
nums = [10,20,30,40,50,60,70,80]
nums[::2]   # [10,30,50,70]
nums[1::2]  # [20,40,60,80]
nums[::-1]  # [80,70,...,10]
07 Lists are Mutable
Concept
  • Elements can be changed after creation (unlike strings/tuples).
  • Mutability makes lists suitable for dynamic programs.
  • Use index assignment: L[i] = new_value
Demo
values = [10, 20, 30, 40]
print(values)        # [10, 20, 30, 40]
values[1] = 99
print(values)        # [10, 99, 30, 40]
08 Slice Assignment
Concept
  • Replaces a slice with a new sequence.
  • Replacement length need not match original slice length.
  • Python removes the slice and inserts all new elements.
Demo
a = [1, 2, 3, 4, 5]
a[1:4] = [20, 30, 40]
print(a)  # [1, 20, 30, 40, 5]

b = [1, 2, 3, 4, 5]
b[1:3] = [9, 9, 9, 9]
print(b)  # [1, 9, 9, 9, 9, 4, 5]
09 Concatenation and Repetition
Concept
  • + joins two lists → new list
  • * repeats elements → new list
  • Neither modifies the originals.
Demo
a = [1, 2, 3]
b = [4, 5]
print(a + b)   # [1, 2, 3, 4, 5]
print(a * 3)   # [1,2,3,1,2,3,1,2,3]
10 Membership: in and not in
Concept
  • Checks if a value exists in a list → True / False
  • in → checks presence
  • not in → checks absence
Demo
nums = [10, 20, 30, 40]
print(20 in nums)      # True
print(25 in nums)      # False
print(50 not in nums)  # True
11 Traversing a List
Direct Traversal
fruits = ["apple", "banana", "mango"]
for item in fruits:
    print(item)
# use when only values needed
Index-Based Traversal
for i in range(len(fruits)):
    print(i, fruits[i])
# use when position also matters
12 append() — Add One Element
Concept
  • Adds exactly one object at the end.
  • Modifies the list in place; returns None.
  • If object is a list, it becomes a nested element.
✗ Mistake: L = L.append(5) → L becomes None
✓ Fix: just write L.append(5) — no assignment needed
Demo
nums = [10, 20, 30]
nums.append(40)
print(nums)   # [10, 20, 30, 40]

a = [1, 2]
a.append([3, 4])
print(a)   # [1, 2, [3, 4]]
13 extend() — Add Multiple Elements
Concept
  • Adds elements one by one from any iterable.
  • When given a string, it appends each character separately.
✗ Mistake: confusing append and extend
✓ Key Rule: append → one object; extend → individual items
Comparison
x = [1, 2]; y = [1, 2]
x.append([3, 4])
y.extend([3, 4])
print(x)   # [1, 2, [3, 4]]
print(y)   # [1, 2, 3, 4]

b = [1, 2]
b.extend("hi")
print(b)   # [1, 2, 'h', 'i']
14 insert(index, value)
Concept
  • Inserts at a specified position.
  • Existing elements shift right.
  • If index > length, inserts at the end (no error).
⚑ Edge case: a.insert(100, 99) on a 3-element list → inserts at end, not error
Demo
nums = [10, 20, 30]
nums.insert(1, 99)
print(nums)   # [10, 99, 20, 30]

a = [10, 20, 30]
a.insert(100, 99)
print(a)   # [10, 20, 30, 99]
15 remove(value) — Delete by Value
Concept
  • Deletes the first occurrence of the value.
  • Second and later occurrences remain.
  • Raises ValueError if value not found.
✗ Mistake: expecting all duplicates to be removed
✓ Fix: use a loop or list comprehension for all removals
Demo
nums = [10, 20, 30, 20, 40]
nums.remove(20)
print(nums)   # [10, 30, 20, 40]
# second 20 still present
16 pop() — Delete by Index and Return
Concept
  • Removes by index and returns the removed element.
  • No index → removes and returns the last element.
  • Accepts negative indices too.
Demo
nums = [10, 20, 30, 40]
x = nums.pop(2)
print(x)      # 30
print(nums)   # [10, 20, 40]

a = [10, 20, 30, 40]
y = a.pop(-2)
print(y)   # 30
print(a)   # [10, 20, 40]
17 del and clear()
Concept
  • del L[i] — deletes by index
  • del L[a:b] — deletes a slice
  • L.clear() — empties the list; list object still exists as []
Demo
nums = [10, 20, 30, 40, 50]
del nums[1]
print(nums)     # [10, 30, 40, 50]

del nums[1:3]
print(nums)     # [10, 50]

nums.clear()
print(nums)     # []
18 index() and count() — Search Methods
Concept
  • .index(v) → position of first occurrence
  • .count(v) → total number of occurrences
  • count(v) == 0 means value absent (safe check)
⚑ Note: len(L) = total size; L.count(x) = frequency of x
Demo
nums = [10, 20, 30, 20, 40, 20]
print(nums.index(20))   # 1 (first only)
print(nums.count(20))   # 3

a = [10, 20, 10, 30]
print(len(a))            # 4
print(a.count(10))      # 2
19 sort() and reverse()
Concept
  • .sort() → ascending order, in place, returns None
  • .sort(reverse=True) → descending
  • .reverse() → reverses current order, in place, returns None
✗ Mistake: L = L.sort() → L becomes None
✓ Fix: just call L.sort()
Demo
nums = [40, 10, 30, 20]
nums.sort()
print(nums)   # [10, 20, 30, 40]
nums.reverse()
print(nums)   # [40, 30, 20, 10]
20 sort() vs sorted() — Critical Distinction
Key Difference
  • .sort() — modifies same list, returns None
  • sorted(L) — returns a new sorted list, original unchanged
⚑ Similarly: L[::-1] creates new reversed list; L.reverse() changes L in place and returns None
Demo
nums = [40, 10, 30, 20]
x = sorted(nums)
print(nums)   # [40, 10, 30, 20] unchanged
print(x)      # [10, 20, 30, 40]

a = [1, 2, 3, 4]
b = a[::-1]
c = a.reverse()
print(a)   # [4,3,2,1] (in-place)
print(b)   # [4,3,2,1] (new list)
print(c)   # None
21 Aliasing — Two Names, One List
Concept
  • b = a does NOT copy the list.
  • Both names point to the same object in memory.
  • Change through one name → reflected in the other.
  • This is called aliasing.
✗ Mistake: assuming b = a creates an independent copy
✓ Fix: use b = a.copy() or b = a[:]
Demo
a = [10, 20, 30]
b = a
b[0] = 999
print(a)   # [999, 20, 30] ← ALSO changed!
print(b)   # [999, 20, 30]

list1 = [1, 2, 3]
list2 = list1
list1.append(4)
print(list2)  # [1, 2, 3, 4]
22 Actual Copy — .copy() or [:]
Concept
  • Creates a new independent list.
  • Changes to copy do not affect original.
  • Two ways: b = a.copy() or b = a[:]
Demo
a = [10, 20, 30]
b = a.copy()
b[0] = 999
print(a)   # [10, 20, 30] ← unchanged
print(b)   # [999, 20, 30]
23 Shallow Copy — Nested List Trap
Concept
  • .copy() works correctly for flat (1D) lists.
  • For nested lists: outer list is copied, but inner lists are still shared.
  • This is shallow copy behavior.
  • For full independence: use copy.deepcopy()
⚑ Important: Modifying inner list elements affects both
Demo
a = [[1, 2], [3, 4]]
b = a.copy()
b[0][0] = 999
print(a)   # [[999, 2], [3, 4]] ← AFFECTED!
print(b)   # [[999, 2], [3, 4]]

# Deep copy solution:
import copy
b = copy.deepcopy(a)
24 Mutation During Loop — Two Traps
Safe: range(len(L)) is pre-computed
L = [1, 2, 3, 4]
for i in range(len(L)):
    L.append(i)
print(L)
# [1, 2, 3, 4, 0, 1, 2, 3]
# len(L) computed ONCE = 4
# loop runs exactly 4 times
Dangerous: iterating directly while mutating
L = [1, 2, 3, 4]
i = 0
for e in L:
    L.append(i)
    i += 1
# Newly added elements also
# get iterated → INFINITE LOOP!
# Avoid mutating while iterating
25 Nested Lists — Lists Inside Lists
Concept
  • A list can contain other lists as elements.
  • Used for matrices, tables, grouped data.
  • Access: L[row][col]
Demo
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
print(matrix[0])      # [1, 2, 3]
print(matrix[1][2])  # 6
print(matrix[2][0])  # 7
26 String ↔ List Conversion
Concept
  • list(s) → breaks string into characters
  • "sep".join(L) → joins list into string
  • join() requires all elements to be strings
✗ Mistake: ''.join([1, 2, 3]) → TypeError
✓ Fix: elements must be strings: ''.join(['1','2','3'])
Demo
s = "python"
L = list(s)
print(L)            # ['p','y','t','h','o','n']
print(''.join(L))   # 'python'

words = ["CSE", "SAARC", "Delhi"]
print(" | ".join(words))
# 'CSE | SAARC | Delhi'
27 List Comprehension
Concept
  • Compact way to build a list: [expr for item in iterable]
  • Can include a filter: [expr for item in iterable if condition]
  • Replaces a for loop + append pattern in one line.
Demo
squares = [x * x for x in range(1, 6)]
print(squares)  # [1, 4, 9, 16, 25]

evens = [x for x in range(1, 21) if x % 2 == 0]

words = ["cat", "elephant", "bat", "dog"]
small = [w for w in words if len(w) <= 3]
print(small)  # ['cat', 'bat', 'dog']
28 Aggregate Functions: min, max, sum
Concept
  • min(L) → smallest element
  • max(L) → largest element
  • sum(L) → total of all numeric elements
  • Reduce the need for manual looping in simple cases.
Demo
nums = [12, 45, 7, 31, 18]
print(min(nums))   # 7
print(max(nums))   # 45
print(sum(nums))   # 113
29 List Unpacking and Comparison
Unpacking
vals = [10, 20, 30]
a, b, c = vals
print(a, b, c)   # 10 20 30
# number of vars must match length
Comparison
a = [1, 2, 3]
b = [1, 2, 3]
c = [3, 2, 1]
print(a == b)   # True
print(a == c)   # False (order matters!)
print(a != c)   # True
30 Tricky Edge Cases — Quick Reference
Methods returning None
L = [2, 1, 3]
L = L.append(5)
print(L)   # None !
# append/sort/reverse/clear
# all return None
{} is dict, not set
a = {}
b = set()
print(type(a))  # dict
print(type(b))  # set
# Always use set() for empty set
extend() with string
a = [1, 2]
a.extend("hi")
print(a)
# [1, 2, 'h', 'i']
# String is iterable!
