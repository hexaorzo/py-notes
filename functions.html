Python Functions

🧩
What is a Function? Core
A function is a reusable block of code with a name, parameters, body, and return value.
Think of it as: Input → Process → Output
  • Reduces code duplication
  • Improves modularity and readability
  • Easier to test and maintain
  • Maps to real-world rules: tax, discount, grade calculators
⚠️
print() vs return — Non-Negotiable Critical
Python
def area_print(r):
    print(3.14159 * r * r)  # side effect only

def area_return(r):
    return 3.14159 * r * r  # value you can reuse

x = area_print(3)  # x = None !
y = area_return(3)  # y = 28.27...
print(y + 10)       # works fine
Output
28.274...
x = None
y = 28.274...
y+10 = 38.274...
Mistake: Using a print()-based function in expressions — it returns None.
Rule: Business logic returns; the UI layer prints. Always compute with return, print outside.

📦
Parameters & Arguments Core
Positional
Python
power(2, 5)  # → 32
power(5, 2)  # → 25
Danger: Same-type swaps fail silently.
Keyword
Python
si(p=1000, r=5, t=2)
si(t=2, p=1000, r=5)
# order doesn't matter
Fix: Use keyword args to prevent silent swap bugs.
Default
Python
def greet(name, msg="Hello"):
    return f"{msg}, {name}"

greet("Raj")         # Hello, Raj
greet("Raj","Hi")  # Hi, Raj
Rule: Non-default params must come BEFORE default params. def f(a=10, b): → SyntaxError. Correct: def f(a, b=10):
🌊
*args and **kwargs Flexible
*args — variable positional
Collects extra positional args into a tuple.
Python
def add_all(*nums):
    return sum(nums)

add_all(1,2,3)    # → 6
add_all(10,20)   # → 30
add_all()        # → 0
**kwargs — variable keyword
Collects extra keyword args into a dict.
Python
def show(**info):
    for k, v in info.items():
        print(k, "=", v)

show(name="Raj", dept="CSE")
# name = Raj
# dept = CSE
Unpacking at call site:
f(*list) unpacks list as positional args.
f(**dict) unpacks dict as keyword args.
🐛
Mutable Default Argument Bug Gotcha
Default values are evaluated once at definition time. A mutable default (like []) accumulates across calls.
Broken ❌
def add_item(x, L=[]):
    L.append(x)
    return L

add_item(10)  # [10]
add_item(20)  # [10, 20] ← surprise!
add_item(30)  # [10, 20, 30] ← worse!
Fixed ✅ — None sentinel
def add_item(x, L=None):
    if L is None:
        L = []
    L.append(x)
    return L

add_item(10)  # [10]
add_item(20)  # [20]  ✓
Note: Use if L is None not if not L — the latter resets even an intentionally empty list passed by the caller.
↩️
Return Patterns Core
Multiple return paths
Python
def grade(m):
    if m < 0 or m > 100:
        return "INVALID"
    if m >= 90: return "A"
    if m >= 75: return "B"
    return "C"
Mistake: Forgetting a final return path → implicit None returned.
Returning multiple values (tuple)
Python
def stats(nums):
    return min(nums), max(nums), sum(nums)/len(nums)

t = stats([10,5,15])   # (5, 15, 10.0)
mn, mx, avg = stats([10,5,15])
Tip: Multiple return values are packed into a tuple automatically. Unpack with matching variable count.

Lambda Functions

λ
What is a Lambda? Core
A lambda is a small, anonymous function defined in a single expression. It can take any number of arguments but only one expression.
  • Syntax: lambda params: expression
  • Returns the result of the expression implicitly
  • Cannot contain statements, assignments, or multiple lines
  • Best used as short, throw-away functions passed to other functions
🔁
Lambda vs def — When to Use Which Comparison
Using def
Python
def square(x):
    return x * x

square(5)  # → 25
Use def when logic is complex, reused many times, or needs a docstring.
Using lambda
Python
square = lambda x: x * x

square(5)  # → 25
# Inline usage (most common)
nums = [3,1,4,2]
sorted(nums, key=lambda x: -x)
# → [4, 3, 2, 1]
Use lambda for short, one-off functions passed as arguments.
🔑
sorted() with key= — Lambda Power Move Practical
Python
nums = [10, 2, 30, 4]
words = ["banana", "kiwi", "fig"]

# Sort by length
sorted(words, key=lambda s: len(s))
# → ['fig', 'kiwi', 'banana']

# Sort by absolute value
sorted([-5,2,-1,3], key=lambda x: abs(x))
# → [-1, 2, 3, -5]

# Case-insensitive sort
sorted(["Raj","amit","Zara"], key=lambda s: s.lower())
# → ['amit', 'Raj', 'Zara']
How key= works:
  • sorted(iterable) returns a new list — original unchanged
  • key= expects a function mapping element → comparison value
  • reverse=True for descending order
  • Sorting is stable — ties preserve original order
Mistake: nums = nums.sort() → becomes None!
Fix: Use nums.sort() (in-place) or nums = sorted(nums) (new list)

map() & filter()

🗺️
map() — Transform Every Element Core
map(func, iterable) applies func to every element and returns a lazy iterator.
Python
nums = [1, 2, 3, 4, 5]

# Square every element
squares = list(map(lambda x: x*x, nums))
# → [1, 4, 9, 16, 25]

# Convert to strings
strs = list(map(str, nums))
# → ['1','2','3','4','5']

# Apply to two lists
a = [1,2,3]; b = [10,20,30]
list(map(lambda x,y: x+y, a, b))
# → [11, 22, 33]
Mistake: print(map(...)) shows <map object at 0x...>
Fix: Wrap in list(...) to materialise results.
How map() works visually
Diagram
Input:   [1,    2,    3,    4,    5]
          ↓     ↓     ↓     ↓     ↓
func:   x*x   x*x   x*x   x*x   x*x
          ↓     ↓     ↓     ↓     ↓
Output:  [1,    4,    9,   16,   25]
map() vs list comprehension:
list(map(lambda x: x*x, nums))
≡ [x*x for x in nums]
🔍
filter() — Keep Elements Matching a Condition Core
filter(func, iterable) keeps only elements where func(element) returns True. Also a lazy iterator.
Python
nums = [1,2,3,4,5,6]

# Keep even numbers
evens = list(filter(lambda x: x%2==0, nums))
# → [2, 4, 6]

# Keep positive numbers
pos = list(filter(lambda x: x>0, [-1,2,-3,4]))
# → [2, 4]

# Keep strings longer than 3 chars
words = ["hi","hello","yes","no"]
list(filter(lambda s: len(s)>3, words))
# → ['hello']
How filter() works visually
Diagram
Input:   [1,    2,    3,    4,    5,    6]
pred: x%2==0: F     T     F     T     F     T
              ✗     ✓     ✗     ✓     ✗     ✓
Output:        [2,         4,         6]
filter() vs list comprehension:
list(filter(lambda x: x%2==0, nums))
≡ [x for x in nums if x%2==0]
filter(None, iterable) removes all falsy values (0, "", None, [], False).
⛓️
Chaining map() and filter() Practical
Python
nums = [1,2,3,4,5,6,7,8]

# Filter evens, then square them
result = list(map(lambda x: x*x,
               filter(lambda x: x%2==0, nums)))
# → [4, 16, 36, 64]

# Equivalent list comprehension
result = [x*x for x in nums if x%2==0]
map vs filter summary: map transforms (same count in/out) · filter selects (fewer or equal out) · both return iterators, wrap in list() to view.

Scope & LEGB Rule

🔭
LEGB — Name Resolution Order Core
Python looks up names in this order, stopping at the first match:
L
Local
Inside the current function
E
Enclosing
Outer function (closures)
G
Global
Module-level variables
B
Built-in
print, len, sum…
Shadowing built-in — Bug!
sum = 10           # shadows built-in sum()
print(sum)          # 10  (ok)
print(sum([1,2,3]))  # TypeError: int not callable!
Never shadow: list, str, sum, max, min, id, type, input, print
Fix: Use descriptive names: total, items, text, result
🌐
global and nonlocal Tricky
global keyword
Python
count = 0

def bad_inc():
    count += 1   # UnboundLocalError!

def good_inc():
    global count
    count += 1   # works ✓

good_inc(); good_inc()
print(count)  # 2
Why UnboundLocalError? Python sees count += and treats count as local — but it hasn't been assigned yet.
nonlocal keyword
Python
def make_counter():
    c = 0
    def inc():
        nonlocal c  # update enclosing c
        c += 1
        return c
    return inc

ctr = make_counter()
print(ctr())  # 1
print(ctr())  # 2
print(ctr())  # 3
nonlocal reaches into the enclosing function's scope (not global). Removing it causes UnboundLocalError.

Closures & Decorators

🔒
Closures — Functions That Remember Core
A closure is an inner function that captures variables from its enclosing scope. The captured variables persist even after the outer function returns.
Python
def make_adder(k):
    def add(x):
        return x + k  # k is "remembered"
    return add

add5 = make_adder(5)
add10 = make_adder(10)
print(add5(7))   # → 12
print(add10(7))  # → 17
Practical: Formula Generators
Python
def make_discount(pct):
    def apply(price):
        return price - (price * pct / 100)
    return apply

d10 = make_discount(10)
d20 = make_discount(20)
print(d10(1000))  # → 900.0
print(d20(1000))  # → 800.0
Closures lock one parameter permanently — cleaner than global variables. Create a new closure for each variant.
🎁
Decorators — Wrapping Functions Advanced
A decorator is a function that takes a function and returns a new enhanced function. It adds behavior before/after the original call without modifying its source.
Basic decorator
Python
def log_call(func):
    def inner(*args, **kwargs):
        print("Calling", func.__name__)
        res = func(*args, **kwargs)
        print("Done")
        return res         # ← must return!
    return inner

@log_call
def add(a, b):
    return a + b

add(10, 5)
# Calling add
# Done
# 15
Common uses
  • Logging — print before/after calls
  • Timing — measure execution time
  • Validation — check inputs before running
  • Caching — memoize expensive results
Bug #1: Forgetting return res inside wrapper → caller always gets None.
Bug #2: Defining wrapper as inner(name) only → breaks for other function signatures. Always use *args, **kwargs.
Quiz

Quick Check

Q01
What does list(map(lambda x: x*2, [1,2,3])) return?
✅ [2, 4, 6] — map applies lambda x: x*2 to each element, then list() materialises the iterator.
Q02
What is the output of list(filter(lambda x: x>3, [1,2,3,4,5]))?
✅ [4, 5] — filter keeps only elements where the predicate is True. x>3 is True for 4 and 5 only.
Q03
What happens when you call add_item(10) twice with the buggy def add_item(x, L=[]):?
✅ The mutable default [] is shared across calls. Second call gets [10, 10]. Fix: use L=None sentinel.
Q04
What does sorted(["banana","fig","kiwi"], key=lambda s: len(s)) return?
✅ ['fig', 'kiwi', 'banana'] — sorted by string length: 3, 4, 6. Original list is unchanged.
Q05
In a decorator, what happens if the wrapper forgets to return res?
✅ The caller always gets None — Python functions return None implicitly when no return statement is reached. Always return res inside the wrapper.
